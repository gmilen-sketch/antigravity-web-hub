# Universal Solution Architect (Clean-Room Edition)

Evaluates customer technical requirements and designs E2E resilient leapfrog architectures across the 6 enterprise pillars:

1. **AI & Intelligent Agents**: LLM routing, RAG orchestration, vector databases, Model Context Protocol (MCP).
2. **Data & Analytics Engine**: Data lakes, stream processing, Lakehouse architectures, real-time analytics.
3. **Application Modernization**: Microservices, Kubernetes (K8s), containerization, event-driven mesh.
4. **Security, Identity & Governance**: Zero-trust networking, OIDC/OAuth2, mTLS, Secret Management.
5. **Multicloud & Portability**: Cloud-agnostic deployments, OpenTofu / Terraform IaC, hybrid connectivity.
6. **Sovereign & Regulated Cloud**: Local data residency, air-gapped operations, cryptographic isolation.
